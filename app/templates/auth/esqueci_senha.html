Esqueceu a senha?

Como o CRM ÔA roda só no seu computador (sem internet), não tem como enviar e-mail de recuperação.

O que fazer:

  1. Peça a outro usuário do sistema para ir em Usuários > Editar > Redefinir senha e criar uma nova senha para você.
  2. Se ninguém mais tem acesso, use o script de emergência:
    1. Abra o Prompt de Comando (cmd) na pasta do CRM
    2. Execute: .venv\Scripts\python.exe resetar_senha.py
    3. O admin voltará à senha padrão oa2026
